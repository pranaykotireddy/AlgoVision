# AlgoVision

A full-stack DSA learning platform with code playground, AI tutor, and 3D visualizations.

## Tech Stack
React, Vite, Tailwind CSS, React Router, Framer Motion, Monaco Editor, Piston API

## Getting Started
```bash
cd frontend
npm install
npm run dev
```


## Status
- Phase 1: Landing page + routing (done)
- Phase 2: Code playground (done)
- Phase 3: AI doubt solver (next)
- Phase 4: 3D visualizer (next)
