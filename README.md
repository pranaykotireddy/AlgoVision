# 🚀 AlgoVision

> A full-stack DSA learning platform with multi-language code playground, AI-powered doubt solver, and 3D algorithm visualizations.

[![License](https://img.shields.io/badge/license-MIT-green)]()
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen)]()

---

## ✨ Features

- 💻 **Code Playground** — Write, run, and test code in 7+ languages (Python, C++, Java, JavaScript, C, Go, Rust)
- 🤖 **AI Doubt Solver** — Get simple explanations of any DSA concept *(coming soon)*
- 🎨 **3D Visualization** — Watch algorithms come alive in interactive 3D *(coming soon)*
- 📚 **Learn Hub** — Topic-wise DSA content with interview notes *(coming soon)*

---

## 🛠️ Tech Stack

**Frontend**
- ⚛️ React 18 + Vite
- 🎨 Tailwind CSS
- 🔀 React Router v6
- 🎬 Framer Motion
- 💻 Monaco Editor (VS Code engine)

**Code Execution**
- ⚙️ Piston API (free, no key needed)

**Planned**
- 🧠 Groq LLM (Llama 3.3) for AI explanations
- 🎮 Three.js + React Three Fiber for 3D
- 🗄️ MongoDB for user progress
